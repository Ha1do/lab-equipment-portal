# 🔬 Lab Equipment Portal

> A web portal for managing and supporting laboratory equipment — built as a bachelor's thesis project.

---

## 📋 About

A PHP-based internal web portal designed to help organizations manage laboratory equipment across multiple labs. The system supports two user roles with distinct capabilities, and revolves around a smart Excel import mechanism that keeps the database in sync with external spreadsheets.

Access is controlled by an administrator — there is no self-registration. The admin creates accounts and provides credentials directly to users.

---

## ✨ Features

### 👤 User

- **Device list** — browse all laboratory equipment on the main page
- **Filtering** — filter by laboratory, category, and status
- **Search** — search by device name or category
- **Sorting** — sort the table by any column
- **CSV Export** — export exactly what you see (filtered/sorted) to a `.csv` file
- **Status indicators** — color-coded availability status visible at a glance (with a legend)
- **Device detail view** — full information about a device
- **Comments** — leave comments on a device, visible in the detail view
- **Usage history** — view who used a device and when
- **User profile** — update personal data, track borrowed equipment, and view personally assigned devices (private — not visible to others)

### 🛠️ Admin

Everything above, plus:

- **Admin panel** with an overview dashboard (total, available, borrowed, archived devices, etc.)
- **Excel import** — import device data from `.csv`, `.xls`, or `.xlsx`
    - If a new SAP number appears → device is created
    - If a SAP number already exists → device data is updated
    - If a device exists in the DB but not in the file → it is **archived** automatically
    - If a new column appears in the file → it is **added to the database** dynamically
- **User management** — create accounts, edit login/password/role, soft-delete via archiving (account stays in DB but login is disabled)
- **Laboratory management** — add, remove, or rename labs and their codes
- **Filter management** — choose which subcategories are visible in the search

## 🔐 Security

- No public registration — accounts are created by admins only
- Passwords stored as **hashed values** in the database
- Protection against **SQL Injection**
- Protection against **Session Fixation**
- Role-based access control (user / admin)

## ⚙️ Setup & Installation

### Requirements

- PHP-compatible web server (e.g. Apache via XAMPP, WAMP, or similar)
- MySQL database
- PHP with PDO/MySQLi support

### Steps

**1. Clone the repository**
```bash
git clone https://github.com/Ha1do/lab-equipment-portal.git
cd lab-equipment-portal
```

**2. Create the database**

Import the SQL script from the `database/` folder into your MySQL instance:
```bash
mysql -u root -p your_database_name < database/structure.sql
```

**3. Configure the connection**

Open `config/config.php` and fill in your database credentials:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'your_database_name');
define('DB_USER', 'your_username');
define('DB_PASS', 'your_password');
```

**4. Deploy to your server**

Place the project folder in your server's web root (e.g. `htdocs/` for XAMPP).

**5. Log in**

Open the app in your browser. You will be greeted by a login page.
The first admin account must be created directly in the database.
